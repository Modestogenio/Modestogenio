## 🚀 Proyectos Destacados (GitHub Showcase)

### 1. [K9 Detection Trainer Pro](https://github.com/Modestogenio/k9-detection-trainer-pro)
* **Vertical:** Adiestramiento Canino K9 · Software de Certificación y Métricas
* **¿Qué resuelve?:** Reemplaza las bitácoras físicas de papel mediante una aplicación offline-first que cuantifica tiempos de reacción, índice de fijación del olor diana (narcóticos/explosivos), curvas de discriminación y genera **informes periciales certificados en PDF**.
* **Stack:** Svelte 5, Chart.js, Dexie.js (IndexedDB PWA), PDF Generation.

### 2. [K9 Detection Trainer (Core Edition)](https://github.com/Modestogenio/k9-detection-trainer)
* **Vertical:** K9 Field Tracking · Operación de Terreno
* **¿Qué resuelve?:** Herramienta táctica para instructores y guías caninos en pistas de adiestramiento, inspección vehicular o paquetería, registrando pasadas, alertas positivas y falsos positivos en tiempo real.
* **Stack:** JavaScript Vanilla, Chart.js, LocalStorage, PWA.

### 3. Gestor de Seguridad Operacional & CCTV Multisucursal *(Repositorio Privado · NDA)*
* **Vertical:** Seguridad Corporativa · Retail Multisucursal y Control de Incidentes
* **Estado:** 🔒 Código propietario resguardado bajo acuerdo de confidencialidad y secreto industrial (NDA). Demostración funcional y de arquitectura disponible en entrevista técnica.
* **¿Qué resuelve?:** Plataforma de bitácora digital para centrales de seguridad (SOC). Centraliza el registro de novedades nocturnas, fiscalización de cobertura de guardias bajo Directivas OS10, auditoría de fallas en grabadores CCTV multisucursal y generación de mapas de calor delictual.
* **Stack:** Python FastAPI, Electron Desktop, React, SQLite/PostgreSQL, Generación automatizada de informes periciales en DOCX/PDF.

### 4. [Comunidad-S.O.S (SOS Vecinos)](https://github.com/Modestogenio/comunidad-sos)
* **Vertical:** Seguridad Vecinal & Alerta Temprana Comunitaria
* **¿Qué resuelve?:** Red de alerta rápida ante incidentes delictuales en barrios y cuadrantes. Cuenta con botón de pánico georreferenciado, mapa interactivo de calor delictual en tiempo real y categorización de eventos sospechosos para coordinación con seguridad municipal.
* **Stack:** Next.js 14, TypeScript, Supabase (PostgreSQL Realtime), Leaflet / OpenStreetMap.

### 5. [CondoSeguro Chile](https://github.com/Modestogenio/condo_seguro)
* **Vertical:** Seguridad Habitacional & Control de Condominios
* **¿Qué resuelve?:** Solución tecnológica de bajo costo para condominios pequeños sin conserjería 24/7. Integra control de accesos, filtro anti-infiltrados para residentes, botón de pánico SOS con enlace directo a Carabineros/Seguridad Municipal y muro oficial libre de spam.
* **Stack:** Python FastAPI, SQLite blindada, Jinja2 Templates, Arquitectura de roles (SuperAdmin / SubAdmin / Residente).

### 6. [SilverTech Chile (Teleasistencia Adultos Mayores)](https://github.com/Modestogenio/silvertech)
* **Vertical:** Seguridad Proactiva y Teleasistencia de la Tercera Edad
* **¿Qué resuelve?:** Ecosistema de asistencia remota para adultos mayores ante emergencias de salud o seguridad doméstica. Dispone de un motor de triage automatizado, monitoreo de adherencia médica y despacho prioritario de alertas a familiares y servicios de urgencia.
* **Stack:** Python (Triage Engine), Supabase Edge Functions, PostgreSQL, Dashboard Web de monitoreo.

### 7. [Home-CCTV](https://github.com/Modestogenio/home-cctv)
* **Vertical:** Videovigilancia Perimetral Distribuida
* **¿Qué resuelve?:** Plataforma de monitoreo y grabación de circuito cerrado de televisión que reutiliza dispositivos móviles o cámaras IP bajo protocolo RTSP, ofreciendo grabación perimetral y almacenamiento de eventos críticos.
* **Stack:** Node.js, Express, FFmpeg, HLS Streaming.
